# 基线与范围

文档状态：持续更新
更新时间：2026-07-27
参考版本：本机安装的 WindTerm 2.6.0（macOS）

## 1. 为什么先锁基线

“一比一复刻”如果没有固定版本、主题、语言、窗口尺寸和操作系统，就无法形成稳定的视觉
和行为验收。不同 WindTerm 版本、Qt 平台主题和系统字体都会导致菜单、控件尺寸和字形发生
变化。

本阶段采用以下默认基线：

| 项目 | 基线 |
| --- | --- |
| 参考应用 | WindTerm 2.6.0 |
| 参考系统 | macOS |
| 界面语言 | 简体中文 |
| 信息架构参考 | WindTerm 工作区与会话流程 |
| 视觉主题 | Apple HIG 启发的浅色/深色系统材料 |
| 标准截图尺寸 | 1440 × 900 逻辑像素，100% 缩放 |
| 串口默认值 | 9600 / 8 / None / 1 / None |
| 默认字符集 | UTF-8 |
| 默认终端 | xterm-256color |
| 默认窗口 | 80 × 24 |
| 默认回滚 | 999,999 行 |

实现仍须支持 Windows 和 Linux；跨平台验收优先验证功能一致，视觉差异按平台分别保存
Golden Screenshot。

## 2. 已核实的 WindTerm 串口能力

本次只读检查了本机应用的 `Info.plist`、`terminal/configs/session.config`、
`global/wind.actions`、菜单/工具栏配置、中文语言包和主题配置，并观察了主工作区。

### 2.1 串口会话参数

- 串口设备（Windows 为 COM，macOS/Linux 为 TTY/CU 路径）
- 波特率，默认 9600
- 数据位，默认 8
- 校验位，默认 None
- 停止位，默认 1
- 流控制，默认 None；资源中存在 RTS/CTS、XON/XOFF
- 会话名称、会话组、图标、描述等通用会话属性
- 字符集、终端类型、行列数、回滚行数等终端属性

### 2.2 主工作区

- 系统标题栏、应用菜单、会话标签栏
- 会话工具条与协议/目标面包屑
- 连接状态提示条
- 中央终端视图
- 左右/底部可停靠窗格
- 底部状态栏
- 多标签、横向/纵向分屏、恢复关闭视图
- 断开、重连、保存会话、会话设置

### 2.3 串口相关工具

- 发送窗格：发送、停止、添加、删除、清空、重复执行和间隔
- 文本发送、行尾处理、键盘输入、粘贴
- Hex 编辑/显示
- 行时间戳、搜索、选择、复制、清屏、清回滚
- 会话日志：不记录、可打印内容、全部输出；覆盖/追加；文件模板和内容模板
- XModem、YModem、ZModem 发送与接收
- 会话触发器
- 同步输入通道

## 3. “一比一”的定义

本项目把“一比一”拆成四个可验收层级。WindTerm 作为信息架构、交互和协议行为参考；
视觉层按后续需求采用 Apple 风格的系统色、材料、圆角与层级，不复制任何 Apple 或
WindTerm 品牌资产：

| 层级 | 定义 | 验收方法 |
| --- | --- | --- |
| 信息架构 | 区域、入口、层级和命名一致 | 页面/菜单对照表 |
| 交互行为 | 点击、快捷键、状态切换、错误反馈一致 | 行为测试用例 |
| 视觉 | Apple 风格主题 token、字号、间距、材料和状态层级一致 | 浅色/深色截图差分 |
| 协议行为 | 串口配置、字节收发、流控、传输结果一致 | 回环与硬件测试 |

不要求：

- 使用 WindTerm 名称、Logo、图标、音频、字体文件或其他原始素材；
- 复制未公开源代码或逆向其内部算法；
- 实现 SFTP、Telnet、Tmux、远程文件管理等未进入需求的扩展协议；
- 在不同操作系统上强行抹平系统标题栏和字体渲染差异。

## 4. 产品边界

### 4.1 纳入范围

- 串口会话的创建、保存、复制、分组、打开、关闭、重连
- 多标签、分屏、可停靠会话树与发送窗格
- 终端模拟、文本/Hex 显示、搜索、时间戳、回滚
- 文本/Hex/文件发送、循环发送和批量命令
- 日志、触发器、X/Y/ZModem
- 设备热插拔、DTR/RTS、Break
- 中英文界面、浅色/深色主题
- 本地配置迁移、崩溃恢复、跨平台安装包
- SSH 配置发现、交互终端与 ADB 设备发现、交互 Shell

### 4.2 不纳入首版

- SFTP/Telnet/Raw TCP/本地 Shell
- 远程文件管理器
- 账号保险箱、应用自建代理、端口转发（OpenSSH 配置中的 ProxyJump 由系统客户端处理）
- Tmux 集成、Shell 自动补全
- 云同步、多人协作、遥测平台
- 插件市场

## 5. 合规约束

WindTerm 官方仓库说明其为“部分开源”，已发布源码按 Apache-2.0 提供。项目采用
clean-room 方法：只使用公开文档、合法运行时观察和明确开源的代码；不搬运应用包内的
品牌素材。产品发布前应完成名称、图标、第三方依赖许可证和商标审核。
