## 1. 状态定义

| 状态 | 含义 |
| --- | --- |
| ✅ 已验证 | 功能已实现，并有自动化测试、CI 编译或已发布安装包证据 |
| 🟡 待外部验证 | 功能已实现，但还需要真实硬件、外部服务或互操作对象完成发布级验证 |
| ⛔ 外部阻塞 | 需要项目所有者提供账号、证书、硬件或法律决策 |
| — 不适用 | 当前平台不提供或不需要该能力 |

“已实现”不等于“已完成所有发布验收”。涉及串口电气信号、驱动、睡眠唤醒、外部 SSH
主机、Android 设备和文件传输互操作的项目，必须保留真实环境测试结果。

## 4. 当前自动化基线

截至本文更新时间：

- 前端：27 个 Vitest 文件、120 个测试；
- 后端：27 个 Rust 测试；
- 浏览器：7 条 Chromium 工作区与 Golden E2E；
- 性能：10 万、50 万、100 万行 xterm.js 解析/回滚/搜索/RSS 基线；
- CI：Linux 质量门禁，以及 Linux、macOS、Windows 桌面编译；
- Release：macOS Apple Silicon/Intel、Windows x64、Linux x64 安装包。

数量会随功能增长而变化，最终结果以当前提交的 CI 页面为准。
