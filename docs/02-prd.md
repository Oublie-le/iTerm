# 产品需求文档（PRD）

文档状态：Draft
产品名称：iTerm
目标版本：v1.0
更新时间：2026-07-26

## 1. 产品概述

iTerm 是面向嵌入式、硬件测试和网络设备工程师的跨平台串口终端。它复刻
WindTerm 串口工作流中最有价值的部分：会话管理、IDE 式多标签工作区、高质量终端、
可复用发送器、日志和文件传输，同时保持完全离线、本地可控。

产品不是 WindTerm 的分发版，也不使用 WindTerm 品牌。对齐目标是用户迁移后无需重新
学习，而不是让两个产品在法律或品牌上混淆。

## 2. 问题陈述

现有轻量串口助手通常缺少成熟终端模拟、会话树、分屏、日志和自动化；通用终端工具则
把串口隐藏在庞大的 SSH/SFTP 功能中。用户需要一个聚焦串口、又具有 WindTerm 工作区
效率的桌面工具。

主要痛点：

- 串口参数和设备路径经常变化，重复配置成本高；
- 启动日志包含 ANSI 控制序列，普通文本框显示混乱；
- 多设备调试需要多标签、分屏和同步发送；
- 长时间测试要求可靠日志、循环发送和触发器；
- 设备拔插、休眠和端口占用时，很多工具反馈不明确；
- Windows/macOS/Linux 上的使用体验不一致。

## 3. 产品目标与非目标

### 3.1 目标

1. 新用户在 60 秒内完成第一次串口连接；
2. WindTerm 串口用户无需说明书即可完成核心工作；
3. 常规串口收发、日志与循环发送零静默丢包；
4. 三个平台使用同一份会话配置和近似一致的工作区；
5. 通过视觉和行为矩阵证明“高保真”，而不是凭主观判断。

### 3.2 非目标

- 不成为全协议远程终端；
- 不提供云账号、云同步或远程控制；
- 不在 v1.0 自建插件生态；
- 不通过复制 WindTerm 原始素材实现视觉相似；
- 不承诺不受硬件、驱动和操作系统限制的任意串口参数。

## 4. 成功指标

### 4.1 产品指标

| 指标 | v1.0 目标 |
| --- | --- |
| 首次连接成功率 | 支持设备场景 ≥ 95% |
| 新建会话至连接的中位时间 | ≤ 60 秒 |
| 连接错误可理解度 | 可用性测试中 ≥ 90% 用户可自行恢复 |
| P0 功能对照覆盖 | 100% |
| P1 功能对照覆盖 | 发布时 ≥ 80%，v1.1 达到 100% |
| 崩溃会话率 | 内测阶段 < 0.2% |
| 用户内容网络上传 | 0 |

### 4.2 工程指标

采用 SRS 的性能、稳定性、视觉和跨平台指标作为发布门槛。

## 5. 版本范围

### 5.1 MVP（内部可用）

- 主窗口骨架与 WindTerm 式布局；
- 串口发现、参数配置、打开/关闭/重连；
- 单会话终端、字符集、ANSI 色彩；
- 键盘输入、粘贴、文本/Hex 单次发送；
- 会话持久化与基础日志；
- macOS + 一个 USB 回环设备打通。

### 5.2 v1.0（公开可用）

- Windows/macOS/Linux；
- 会话树、多标签、布局恢复；
- 搜索、时间戳、Hex 视图、百万行回滚目标；
- 多发送器、循环发送、文件发送；
- DTR/RTS/Break、设备热插拔；
- SSH 配置自动发现与一键连接、ADB 设备发现与交互 Shell；
- 日志配置与滚动；
- 中英文、Apple 风格浅色/深色主题；
- 命令历史/快捷联想、终端字号缩放和右键操作；
- 完整错误状态和安装包。

### 5.3 v1.1（高级对齐）

- 分屏与同步输入；
- X/Y/ZModem；
- 触发器；
- 命令模板导入导出；
- 更完整的终端设置与快捷键自定义。

## 7. 页面与交互规格

### 7.1 主工作区

从上到下：

1. 系统标题栏；
2. 应用菜单栏；
3. 会话标签栏：状态色块、序号、会话名、关闭按钮；
4. 会话工具栏：新建、关闭、会话属性、协议与目标面包屑、重连、更多；
5. 可关闭的状态通知条；
6. 中央终端；
7. 可选底部发送窗格；
8. 状态栏：模式、行列、光标位置、编码/终端、时间、连接状态。

左侧默认显示会话树。窗格可隐藏和调整宽度；隐藏后终端填充剩余空间。

### 7.2 新建串口会话

对话框使用左侧分类树 + 右侧设置页：

- **会话**：协议固定为“串口”，设备、会话名称、会话组、描述；
- **串口**：波特率、数据位、校验位、停止位、流控制；
- **终端**：字符集、终端类型、Answerback、键位；
- **窗口**：行列、回滚、时间戳、光标、自动换行；
- **日志**：类型、覆盖/追加、文件名模板、内容模板、大小上限；
- **传输**：X/Y/ZModem 参数；
- **高级**：自动重连、DTR/RTS 初始状态。

主操作：

- “连接”：校验、保存会话、关闭对话框并连接；
- “保存”：保存但不连接；
- “取消”：不保存修改；
- 设备列表旁提供刷新按钮。

首次打开默认 9600/8/N/1/None；设备列表仅一个可用项时自动选中，但不自动连接。

### 7.3 终端状态

| 状态 | 标签 | 工具栏 | 通知条 | 输入 |
| --- | --- | --- | --- | --- |
| Disconnected | 灰色 | 显示连接 | 可选原因 | 禁用 |
| Opening | 黄色/旋转 | 显示取消 | “正在打开…” | 禁用 |
| Connected | 绿色 | 显示断开/重连 | 隐藏 | 启用 |
| DeviceLost | 红色 | 显示重试 | “设备已断开” | 禁用 |
| Error | 红色 | 显示重试 | 错误 + 建议 | 禁用 |

按 Enter 重连只在通知条明确提示后生效，避免用户误触占用端口。

### 7.4 发送窗格

- 顶部工具条：发送、停止、添加、删除、清空；
- 每个发送器是可切换标签或列表项；
- 主体为多行输入框；
- 底部为模式（Text/Hex）、行尾、重复执行、间隔和发送统计；
- 发送期间锁定会改变有效负载的控件；
- 停止后保留文本和配置；
- `Ctrl/Cmd + Click` 可作为快速发送手势，但必须有常规按钮替代。

### 7.5 Hex 视图

显示偏移、Hex 字节和 ASCII 三栏；支持列数和分组；接收与发送使用不同但可配置的颜色。
文本/Hex 切换共用同一份原始字节源，不能通过重新编码文本构造 Hex。

### 7.6 日志

开始日志后状态栏显示记录中图标和目标文件。磁盘错误使用非模态错误条提示，并提供
“更换目录”和“重试”。停止日志不关闭会话。

## 8. 视觉规格

工作区信息架构和操作密度参考 WindTerm；视觉主题以 Apple HIG 的清晰层级、系统色、
半透明材料、适度圆角和平台字体栈为设计方向：

| Token | 参考值 |
| --- | --- |
| `surface.workspace.light` | `#f5f5f7` |
| `surface.workspace.dark` | `#161618` |
| `text.primary.light` | `#1d1d1f` |
| `text.primary.dark` | `#f5f5f7` |
| `accent.primary.light` | `#007aff` |
| `accent.primary.dark` | `#0a84ff` |
| `material.sidebar` | 半透明背景 + saturation/blur；减少透明度设置下退化为不透明 |
| `status.error` | `#ff3b30` / `#ff453a` |
| `font.ui` | 系统 `-apple-system` 优先，跨平台安全回退 |
| `font.mono` | SFMono / Roboto Mono / Consolas / 系统等宽 |
| `font.size.default` | 14 px，可在 8–40 范围快捷缩放 |

最终不能直接分发 WindTerm 自带字体或图标文件；应使用允许再分发的上游字体包和独立图标。

视觉资产流程：

1. 为基线页面保存无遮挡截图；
2. 标注区域、尺寸、间距、颜色和交互状态；
3. 转换为设计 token 和组件规格；
4. Storybook 独立实现；
5. 用截图差分收敛；
6. 人工复核字体抗锯齿、系统菜单等不可比区域。

## 9. 文案原则

- 优先给出“发生了什么 + 为什么 + 怎么恢复”；
- 使用设备友好名称和实际路径，例如 `CP2102 (cu.usbserial-0001)`；
- 不直接展示底层 Rust/OS 错误码，错误码放在“详情”；
- 删除会话、停止传输、退出活动连接需要确认；
- 普通断开、刷新列表等可恢复操作不使用阻塞弹窗。

## 10. 隐私与安全

- 默认完全离线，不发送遥测；
- 不把串口输出写入系统剪贴板、日志或历史，除非用户主动操作；
- 粘贴大量文本时显示预览和字节数；
- 导入配置和打开链接视为不可信输入；
- 日志可能含密钥和设备信息，隐私说明需明确本地存储位置；
- 更新检查若启用，必须与串口数据通道完全隔离。

## 11. 开放问题

编码前必须确认：

1. 最终以 WindTerm 2.6.0 还是另一个版本作为视觉基线；
2. v1.0 是否必须包含 X/Y/ZModem、触发器和分屏；
3. 第一优先平台是 Windows 还是 macOS；
4. 100 万行回滚是硬门槛，还是允许屏幕保留较少行、完整内容落盘；
5. 是否需要自定义品牌名、图标和安装包签名主体；
6. 是否需要兼容 WindTerm 会话配置导入。
