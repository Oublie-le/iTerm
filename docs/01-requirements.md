# 软件需求规格说明书（SRS）

文档状态：Draft
产品名称：iTerm
版本目标：v1.0
更新时间：2026-07-26

## 1. 目的

本文定义跨平台串口终端的功能、数据、质量和验收要求。需求采用唯一编号，后续设计、
测试用例和发布检查必须回链到这些编号。

优先级：

- **P0**：v1.0 发布阻断项；
- **P1**：高保真版本需要，允许在 v1.1 补齐；
- **P2**：增强项。

## 2. 用户与典型场景

### 2.1 用户角色

| 角色 | 主要任务 |
| --- | --- |
| 嵌入式工程师 | 查看启动日志、进入 Bootloader、烧录/传输文件 |
| 网络设备工程师 | 通过 Console 口配置交换机、路由器 |
| 硬件测试工程师 | 循环发送指令、记录响应、长期稳定性测试 |
| 教学/实验用户 | 连接开发板、观察串口输出、保存实验日志 |

### 2.2 核心用户旅程

1. 插入 USB 转串口设备；
2. 新建串口会话并选择设备；
3. 配置 115200/8/N/1/无流控并连接；
4. 在终端查看带 ANSI 色彩的启动输出；
5. 使用键盘或发送窗格发送命令；
6. 开启时间戳和日志；
7. 设备断开后得到明确提示，插回后手动或自动重连；
8. 下次启动恢复会话与工作区布局。

## 4. 数据需求

### 4.1 核心实体

| 实体 | 关键字段 |
| --- | --- |
| SessionProfile | id、name、groupId、serialConfig、terminalConfig、loggingConfig |
| SessionGroup | id、parentId、name、sortOrder |
| WorkspaceLayout | window、docks、tabs、splits、activeSession |
| SenderPreset | id、sessionId、mode、payload、lineEnding、interval |
| TriggerRule | id、sessionId、matcher、action、cooldown、limit |
| RecentSession | profileId、lastOpenedAt、lastResult |
| AppSetting | key、value、schemaVersion |

### 4.2 数据规则

- 所有持久化对象有稳定 UUID；
- 配置数据库必须带 schema version，升级需事务迁移；
- 端口实时状态和活动句柄不得持久化；
- 串口字节流默认仅存在内存，只有用户开启日志时写入文件；
- 删除会话不删除既有日志；
- 用户可从设置中清空历史与布局，不影响会话配置。

## 6. 错误与边界条件

- 设备被其他进程占用；
- 会话连接时设备被拔出；
- 同名端口对应了不同 USB 设备；
- 自定义波特率被驱动拒绝；
- 日志目录不可写或磁盘写满；
- UTF-8/GBK 字符恰好跨读取边界；
- 接收速率高于前端渲染速率；
- 粘贴超大文本或循环发送间隔过小；
- X/Y/ZModem 中途断线；
- 睡眠/唤醒后句柄失效；
- 应用升级时配置迁移失败。

每一项都必须有自动化测试或硬件测试用例，并定义可恢复路径。

## 7. 发布验收

v1.0 发布需同时满足：

1. 所有 P0 需求通过，且无未批准的行为偏差；
2. 标准功能矩阵 Windows/macOS/Linux 全通过；
3. 3 种 USB 转串口芯片完成硬件冒烟测试；
4. 30 分钟高吞吐与 24 小时稳定性测试通过；
5. P0 页面视觉 Golden 测试达到阈值；
6. 安装包签名、许可证清单、隐私说明和升级/回滚文档齐备。
