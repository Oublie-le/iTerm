# 数据与隐私说明

生效日期：2026-07-27  
适用版本：iTerm 0.x  
应用标识：`com.oubliele.iterm`

## 1. 原则

iTerm 是本地优先的桌面工具。应用不包含项目方账号系统、广告 SDK、遥测 SDK或云端同步，
不会把会话配置、终端内容、日志或诊断记录上传到项目方服务器。

当用户主动建立 SSH、ADB 或网络设备连接时，数据会发送到用户指定的目标。系统
OpenSSH 和 ADB 客户端还可能使用各自的配置、代理、Agent 和已知主机文件；这些行为由
相应外部工具及用户配置控制。

## 2. 本地数据清单

| 数据 | 内容 | 保存位置 | 默认保留 |
| --- | --- | --- | --- |
| 会话配置 | 协议、主机、用户名、串口参数、设备 ID、私钥路径等 | 应用数据目录中的 `iterm-state.sqlite3`，运行时同步到 WebView Storage | 直到用户删除配置或应用数据 |
| 应用偏好 | 语言、主题、默认终端和日志参数 | 同上 | 直到重置应用数据 |
| 工作区 | 打开的会话 ID、活动会话、侧栏/发送窗格和分屏布局 | 同上 | 直到重置应用数据 |
| 发送器模板 | 模板名称、文本或 Hex 内容、行尾和循环参数 | 同上 | 直到用户删除模板或应用数据 |
| 终端收发内容 | 当前会话的接收缓冲和终端回滚 | 仅进程内存 | 会话关闭或应用退出 |
| 会话日志 | 用户明确启用后记录的原始字节或文本 | Tauri 解析的系统应用日志目录 | 直到用户手动删除；可按设置轮转 |
| 接收文件 | YModem/ZModem 接收的文件 | 用户选择的目录 | 由用户管理 |
| 本地诊断 | 最多 500 条结构化状态/错误事件 | WebView Storage | 先进先出；可在应用设置中清空 |
| 导出文件 | 会话 JSON、发送器 JSON、诊断 JSON | 用户选择的位置 | 由用户管理 |

可以通过工具栏的“打开日志目录”定位当前系统实际使用的日志目录。应用数据目录由
操作系统和 Tauri 根据应用标识解析，不建议在应用运行时直接修改数据库。

## 3. 凭据和敏感内容

- SSH 密码和键盘交互响应直接输入系统 OpenSSH 伪终端，不由 iTerm 读取或持久化；
- 使用指定私钥时只保存私钥文件路径，不复制私钥内容；
- SSH Agent、`known_hosts` 和 `~/.ssh/config` 由系统 OpenSSH 管理；
- iTerm 不保存 ADB 密钥；ADB 授权由本机 ADB 客户端管理；
- 终端收发字节、文件内容、密码、令牌和私钥路径不会写入结构化诊断导出；
- 诊断上下文按敏感字段名脱敏，字符串最长保留 500 个字符，消息最长保留
  1,000 个字符。

会话配置导出可能包含主机名、用户名、设备 ID、串口序列号和私钥路径；发送器导出可能
包含用户输入的命令文本。分享这些文件前应自行检查。

## 4. 网络访问

iTerm 本身没有项目方云服务。以下网络活动只在用户明确操作或外部工具配置要求时发生：

1. SSH 会话连接用户填写的主机和端口；
2. 网络 ADB 连接用户填写的 `IP:端口`；
3. 串口连接不需要网络；
4. 当前版本没有自动更新检查。

GitHub README、下载和文档链接只会在用户主动打开时由系统浏览器访问。

## 5. 用户控制和删除

- 单个会话配置可在会话管理器中删除；
- 诊断记录可在“应用设置 → 本地诊断”中清空；
- 日志和接收文件可在对应目录中手动删除；
- 导出文件由用户在选择的位置自行删除；
- 完全清除时，应先退出 iTerm，再删除操作系统中
  `com.oubliele.iterm` 对应的应用数据、WebView Storage 和应用日志目录。

仅删除 `iterm-state.sqlite3` 可能不足以完成重置，因为 WebView Storage 中的既有配置可在
下一次启动时重新迁移到数据库。当前版本尚未提供一键“恢复出厂设置”。

## 6. 安全边界

- 日志目录以外的文件不能通过“打开日志文件”命令打开；
- SQLite 只接受预定义的五类配置键，并限制单项大小；
- 接收文件名会移除路径成分，避免覆盖目标目录之外的文件；
- 应用不会通过 shell 字符串拼接执行 SSH 或 ADB 参数；
- 未签名预览包可能触发操作系统安全提示，这与数据上传无关。

## 7. 变更

当数据类型、默认保留策略、网络服务或遥测行为发生变化时，应在发布前更新本文和
`CHANGELOG.md`。若未来增加自动更新，应单独说明更新端点、请求字段和关闭方式。
